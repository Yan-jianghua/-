# 共振星门联机实现

每个游戏账号只占一个席位，每席只允许一个活动连接。HTTP 注册和登录使用加盐 scrypt 密码摘要。先用 Bearer 会话申请一次性票据，再用票据建立 WebSocket；票据限时 15 秒。账号摘要保存在 server/data/accounts.json。会话和房间保存在进程内，重启后重新登录并建房。

服务端每 50 毫秒推进物理，并按席位发送快照。两端各自仅发送移动方向和当前关卡的共振操作。每次生成星门时打乱符文，只给每个账号显示搭档落点的线索。第一关直接读符文，第二关沿三符文循环前进一步，第三关前进两步。三关分别要求水平标准带长、反向收紧、纵向拉长。两端在正确位置和带长范围内发出共振，服务端按收到操作的时间计算 300 毫秒窗口。高延迟条件下的手感需要实机调校。

队友离线时暂停物理并清空输入。可重连到原席位，双端离线十分钟后清理房间。主动退出会关闭房间。三人满房、重连、双端共胜和重开使用独立账号通过正常网络接口进行回归验证，运行方式为在 server 目录执行 npm test。

当前开发版采用单服务进程。公网域名、TLS、注册频率限制及公网环境测试留待上线前完成。
