## 核心内容速览

- **一句话**：两颗球球，一根光带，一起滚过一颗会呼吸的小星球。
- **核心机制**：缘分光带——两人共用"一只手"，7 个动词（弹弓/摆荡/缠绕/拉拽/共振/收放/打结）× 6 颗星球规则 = 42 种正交组合。
- **玩法矩阵**：星旅主线（6 星球 × 48 关）、星环派对（20 迷你游戏）、共振密室（每日 1 间）、小行星窝（家园养成）、漂流心事（每日一问）、星球工坊（UGC）、流星季（赛季 Raid）。
- **六大硬约束**（§2.1 验收表）：稳定 / 创新 / 可爱温馨 / 可玩性好 / 考验配合默契 / 考验智力。
- **稳定性**：99.9% 可用性、崩溃率 <0.3%、150ms+5% 丢包可通关、断线 8 秒恢复、服务端权威 + 定点数物理 + 回滚 + 灰度回滚。
- **商业化**：纯外观 + 双人共享赛季通行证 + 实体回忆册，无抽卡、不卖数值。
- **路线**：14 个月、11–14 人、首年预算约 ¥1200–1900 万（验证版可压到 ¥600 万内）。
